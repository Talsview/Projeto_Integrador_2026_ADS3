# ADR-063 — Comentários explicativos nos métodos e nos padrões de projeto

## Status

Aceita.

## Contexto

O Projeto Integrador exige que o código-fonte do sistema seja apresentado com clareza, validações e justificativas técnicas. Além disso, os padrões de projeto aplicados precisam ser identificáveis e defensáveis, demonstrando que agregam funcionalidade real ao sistema.

Durante a preparação final, foi identificada a necessidade de melhorar a legibilidade do código por meio de comentários nos métodos e nos pontos onde os padrões de projeto são aplicados.

## Decisão

Adicionar comentários simples e objetivos nos métodos do backend e do frontend, descrevendo a finalidade de cada método.

Nos padrões de projeto, adicionar também justificativas acadêmicas e funcionais, explicando por que o padrão existe no sistema e qual problema ele resolve.

## Consequências

### Positivas

- Facilita a leitura do código pelo professor e pela equipe.
- Ajuda na apresentação e defesa oral do sistema.
- Evidencia que os padrões de projeto não foram aplicados de forma artificial.
- Melhora a manutenção futura do projeto.

### Negativas

- Aumenta o volume textual do código-fonte.
- Exige cuidado para manter comentários atualizados caso a regra do método seja alterada no futuro.

## Decisão final

A decisão foi aceita por estar alinhada ao objetivo acadêmico do projeto, à necessidade de rastreabilidade técnica e à exigência de justificar os padrões de projeto implementados.
