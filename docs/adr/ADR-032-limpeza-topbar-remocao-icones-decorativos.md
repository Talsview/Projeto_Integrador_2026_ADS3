# ADR-032 — Limpeza da barra superior e remoção de ícones decorativos

## Status

Aprovada.

## Contexto

A interface reformulada possuía busca global, botão de notificação, botão visual de modo escuro e símbolos decorativos. Para o contexto do sistema da oficina, esses elementos não possuíam funcionalidade operacional completa e deixavam a interface com aparência menos objetiva.

## Decisão

Remover a busca global da barra superior, retirar o ícone de notificação, retirar o botão de modo escuro e substituir emojis/símbolos por siglas funcionais no menu e na tela inicial.

## Consequências

A interface fica mais limpa, direta e adequada para apresentação como sistema administrativo de oficina mecânica. A decisão não altera endpoints, services ou regras de negócio.
